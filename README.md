# customer-churn-prediction in creation
End-to-end ML pipeline predicting telecom churn | XGBoost · Scikit-learn · Streamlit | F1-score: 84%
An end-to-end Machine Learning project that predicts customer churn in the telecom industry using XGBoost, Scikit-learn, and Streamlit. The model analyzes customer information to identify users who are likely to discontinue their services, helping businesses make data-driven retention decisions.
